# IT Role Profiles Lab

Исследовательская среда к статье «Устойчивость технологических профилей IT-ролей к выбору метрики и порога отбора по данным Stack Overflow Developer Survey 2025».

Сайт показывает сводные результаты: профили семи IT-ролей при разных знаменателях, фонах, выборках и порогах, эквивалентные пороги, согласованность правил взвешивания и устойчивость top-10 в 1 000 бутстреп-выборках. Индивидуальные ответы респондентов не публикуются.

## Данные
Stack Overflow Developer Survey 2025, файл `survey_results_public.csv` (49 191 строка),

## Файлы
- `index.html` - разметка страниц
- `styles.css` - цвета, шрифты, оформление
- `app.js` - логика: переключатели, пересчет таблиц
- `data.js` - сводные результаты расчетов
